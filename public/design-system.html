The Visual Language of Elementa

Elementa is built on four core principles: academic clarity, structural restraint, subject-reactive dynamic theming, and glassmorphic elevation. Every token in this guide is mathematically aligned to support both high-focus study and seamless cross-platform implementation.

Foundations Part 4

Borders, Radii & Geometry

Elementa applies rounded geometry hierarchically. Small interactive widgets carry 12px radii, content cards carry 16px to 24px radii, and focal interactive portals carry up to 40px radii. Full pills are reserved for buttons, status chips, and progress tracks.

Micro 4px (0.25rem) Skeleton text, chips
Medium 12px (0.75rem) Buttons, inputs
Large 16px (1rem) Cards, rows, modal inputs
Jumbo 24px (1.5rem) Admin cards, hubs
Maximum 40px (2.5rem) Subject tiles, hero
Full Pill 9999px (full) Avatars, tracks, pills

Border Density Standard

All dividers and outlines must strictly use 1px width with opacity tints. Never use 2px or solid black borders.

Architecture Part 6

Layout Grid & Mobile Rules

Elementa employs a fixed sidebar on desktop that transitions smoothly into a full-screen mobile slide-out drawer below 1024px.

aside.fixed w-64 (16rem) h-screen, z-50
hidden lg:flex
header.fixed (lg:w-[calc(100%-16rem)]) h-20, z-40, blur(24px)
main.ml-0 lg:ml-64 pt-20 or pt-24 min-h-screen px-4 lg:px-12

Desktop Layout (> 1023px)

  • Sidebar is fixed at 16rem width with an independent scroll track.
  • Main viewport applies ml-64 margin offset.
  • Top header bar spans w-[calc(100%-16rem)] fixed to top right.
  • Search input is fully expanded with 24rem width.

Mobile & Tablet (≤ 1023px)

  • Sidebar is hidden via display: none !important.
  • Header bar spans full width (100%) with hamburger toggle on left.
  • Full-screen drawer slides in from right (translate-x-full transition).
  • Minimum tap target is 44px on all interactive icons and links.

Elementa avoids generic spinning wheels in favor of custom-calibrated skeleton placeholders with a linear 1.5s light-pass gradient shimmer.

  100% { background-position: 200% 0; }

// 1. Time string formatter (e.g. 1869s -> 31:09)
const formatMins = (seconds) => {
  if (!seconds || isNaN(seconds)) return '0:00';
  const h = Math.floor(seconds / 3600);
  const m = Math.floor((seconds % 3600) / 60);
  const s = Math.floor(seconds % 60);
  if (h > 0) return `${h}:${m.toString().padStart(2, '0')}:${s.toString().padStart(2, '0')}`;
  return `${m}:${s.toString().padStart(2, '0')}`;
};

// 2. Real-time watch progress calculation (0 to 100 integer)
const formatProgress = (watched, duration) => {
  if (!watched || !duration || duration === 0) return 0;
  return Math.min(100, Math.floor((watched / duration) * 100));
};

// 3. Subject Switcher
function switchSubject(subjectName) {
  document.body.setAttribute('data-subject', subjectName);
  document.cookie = `activeSubject=${subjectName}; path=/; max-age=28800; SameSite=Strict`;
}
